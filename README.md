# EVERYDAY — Prototype v0.2

A lightweight, mobile-friendly PWA for **EVERYDAY** — designed to bring a little something engaging, thoughtful, and creative to every single day.

---

## What's New in v0.2
- **Supabase Authentication:** Passwordless magic-link email login for a smooth, frictionless user experience.
- **Dual Local & Cloud Sync:** Use the app anonymously in **Guest Mode** (with browser `localStorage`) or log in to sync activity progress across devices.
- **Refined Vibrant Aesthetic:** Elevated UI with high-contrast Electric Indigo and Rose accents.
- **Service Worker & PWA Support:** Fully offline-capable PWA with automatic cache management for static assets and API bypass for real-time authentication.
- **Interactive Community Wall:** Local and cloud-backed prompt sharing.

---

## App Features
- **Mood-Based Selection:** Explore tailored activities across *Curious*, *Playful*, *Creative*, *Social*, *Productive*, and *Relaxed*.
- **Interactive Content:** Trivia, riddles, creative challenges, and daily thought prompts.
- **PWA Installation:** Install directly to mobile home screens or desktops as a standalone app.
